
# Praktikum 8 - PHP dan Database

## Data Barang

Program ini merupakan aplikasi sederhana untuk mengelola data barang menggunakan PHP dan MySQL.

## Fitur
1. Menampilkan data barang.
2. Menambahkan barang.
3. Mengubah data barang.
4. Menghapus barang.
5. Mengunggah gambar barang.

## Teknologi
- PHP
- MySQL
- phpMyAdmin
- HTML
- CSS
- XAMPP

## Struktur File
- koneksi.php
- index.php
- tambah.php
- ubah.php
- hapus.php
- style.css
- folder gambar/
